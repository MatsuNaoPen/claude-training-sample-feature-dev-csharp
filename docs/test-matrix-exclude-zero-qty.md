# テスト観点マトリクス: 数量 0 の明細を合計から除外

| 区分 | 観点 | 入力 | 期待 |
|---|---|---|---|
| 正常系 | 数量 1 以上の明細は含める | 数量 2 × 単価 1000 + 送料 300 | 2300 |
| 正常系 | 数量 0 の明細は除外（送料も） | 数量 0 × 単価 500 + 送料 300 と 数量 1 × 1000 | 1000 |
| 正常系 | 数量 0 と 1 以上の混在 | 3 明細（うち 1 つが数量 0） | 数量 0 以外の合計 |
| 正常系 | 一覧全体の合計でも除外 | 2 注文（片方に数量 0 の明細） | 数量 0 以外の合計 |
| 境界値 | 数量 1 | 数量 1 × 単価 800 | 800 |
| 境界値 | 数量 0 の明細のみ | 数量 0 × 単価 800 | 0 |
| 境界値 | 負数 | 数量 -1 | `ArgumentOutOfRangeException` |
| 境界値 | 上限 9999 | 数量 9999 × 単価 1 | 9999 |
| 境界値 | 上限超過 10000 | 数量 10000 | `ArgumentOutOfRangeException`（既存） |
| 異常系 | 明細に null | Lines に null を含む | `ArgumentNullException` |
| 異常系 | 注文が null | null | `ArgumentNullException`（既存） |
