# 仕様: 数量 0 の明細を合計から除外する

## 対象
- 注文一覧の合計計算（`OrderTotalService`）: 注文ごとの合計（`CalculateOrderTotal`）と一覧全体の合計（`CalculateGrandTotalAsync`）

## 振る舞い
- 数量が 0 の明細は、合計金額に含めない
- 明細自体は削除せず、一覧には残す（表示・永続化には手を入れない）

## 境界条件
| 数量 | 扱い |
|---|---|
| 0 | 合計から除外 |
| 1 以上 | 合計に含める |
| 負数 | `ArgumentOutOfRangeException` |
| 上限 | 既存の仕様に従う（9999 まで。超過は例外） |

## 影響範囲
- `OrderTotalService` のみ。表示・永続化・他サービスには手を入れない

## 要確認
- 数量 0 の明細に送料（`ShippingFee`）が紐づく場合の扱い → **本デモでは「送料も除外」とする**
