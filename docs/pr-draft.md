# 数量 0 の明細を合計金額から除外する

## 変更概要
- 注文合計・一覧合計の計算で、数量 0 の明細を除外した（明細の送料も含めない）
- 数量が負数の明細は `ArgumentOutOfRangeException` を投げるようにした
- 明細自体は削除せず、一覧には残る（表示・永続化は変更なし）

## 仕様書
- docs/spec-exclude-zero-qty.md

## テスト観点
- docs/test-matrix-exclude-zero-qty.md（正常系 4・境界値 5・異常系 2）
- テストを実装より先に書き、実装前は「数量 0 の明細の送料が残る」「負数で例外が出ない」の 2 件が失敗することを確かめてから実装した（テストは変更していない）

## レビューで見てほしい点
- 「送料も除外」の判断は仕様書の要確認事項を仮置きしたもの。業務上の妥当性
- 負数を例外にしたことで、既存の呼び出し元に負数の明細が流れてくる経路がないか
